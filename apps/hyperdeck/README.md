# HyperDeck

Status: **preview** · Owner: `@hyperoffice/apps`

Presentations for `.pptx` (opens `.pptm`, `.potx`, `.ppsx`; saves `.pptx`).

| Folder | Contents |
| --- | --- |
| `src/editor/` | Slide rail, slide canvas, toolbar, full-screen presenter (F5), stylesheet |
| `src/slides/` | Slide list operations (add, delete, move, RTL) |

Supported subset and known losses: `compatibility/manifests/pptx.json`.

Installer: `exe/HyperDeck-Setup-0.1.0.exe` (built by `apps/desktop`).
