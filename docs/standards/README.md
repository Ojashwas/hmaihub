# Standards register

Public specifications HyperOffice implements from. Observed behaviour (REA
investigations) supplements but never replaces these.

| Area | Reference |
| --- | --- |
| OOXML | ECMA-376 / ISO/IEC 29500 Parts 1–4 (WordprocessingML, SpreadsheetML, PresentationML, DrawingML, OPC) |
| Office implementation notes | Microsoft Open Specifications: [MS-OI29500], [MS-DOCX], [MS-XLSX], [MS-PPTX], [MS-OE376] |
| Legacy binary | [MS-CFB], [MS-DOC], [MS-XLS], [MS-XLSB], [MS-PPT], [MS-OFFCRYPTO], [MS-OVBA] |
| Project interchange | Microsoft Project XML schema (MSPDI) |
| OpenDocument | OASIS ODF 1.3 / ISO/IEC 26300 |
| PDF | ISO 32000-2; PDF/UA (ISO 14289) for accessible export |
| Accessibility | WCAG 2.2 AA, WAI-ARIA 1.2 |
| Tokens | RFC 7515 (JWS), RFC 7517 (JWK), RFC 8037 (OKP/EdDSA in JOSE), RFC 8032 (Ed25519), RFC 8725 (JWT BCP) |
| Data | RFC 8259 (JSON), JSON Schema 2020-12, OpenAPI 3.1 |
| ZIP | PKWARE APPNOTE |

Leaked or confidential documentation must never be used.
